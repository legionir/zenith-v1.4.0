⚡ Signal & Reactivity

قلب واکنش‌گرایی فریم‌ورک — signal، effect، computed و dependency tracking

signal effect computed dependency-tracking batching

۱. Signal پایه

یک signal ظرفی واکنش‌گراست. وقتی مقدارش با set() عوض شود، تمام DOMهای وابسته به‌طور خودکار آپدیت می‌شوند.

مقدار فعلی: — با کلیک روی دکمه‌ها، DOM بدون هیچ کد دستی آپدیت می‌شود.

۲. Computed (مقدار مشتق‌شده)

computed(() => count.get() * 2) یک مقدار فقط‌خواندنی می‌سازد که از روی Signalهای دیگر محاسبه می‌شود. وقتی count تغییر کند، doubled هم به‌طور خودکار آپدیت می‌شود.

count = 0 doubled = 0 squared = 0 
const count   = signal(0);
const doubled = computed(() => count.get() * 2);
const squared = computed(() => count.get() * count.get());

۳. Effect (عوارض جانبی واکنش‌گرا)

این effect هر بار که count تغییر کند، یک خط به log اضافه می‌کند. خود فریم‌ورک همین مکانیزم را برای آپدیت DOM استفاده می‌کند.

۴. چندین Signal + zen-model

دو Signal جداگانه برای نام و نام خانوادگی. fullName یک computed است که از هر دو می‌خواند. inputs با zen-model دوطرفه متصل شده‌اند.

نام کامل: 

const firstName = signal('علی');
const lastName  = signal('احمدی');
const fullName  = computed(() => firstName.get() + ' ' + lastName.get());
// در HTML: <input zen-model="$firstName">

۵. Signal با مقدار Object

یک Signal می‌تواند هر نوعی داشته باشد — حتی Object. برای trigger کردن reactivity، یک Object جدید (با reference متفاوت) در set() قرار می‌دهیم.

name = age = 
const user = signal({ name: 'علی', age: 25 });
// Action:
user.set({ name: 'محمد', age: 30 });  // Object جدید → reactivity

۶. Dependency Tracking (ردیابی دقیق)

هر Effect فقط به Signalهایی وابسته است که در بدنه‌اش .get() شده‌اند. در این مثال، effectA فقط count می‌خواند و effectB فقط unrelated. وقتی unrelated را تغییر می‌دهیم، effectA نباید اجرا شود — و نمی‌شود!

count = unrelated = effectA runs (خواندن count) = 0 effectB runs (خواندن unrelated) = 0

امتحان کنید: وقتی count را زیاد می‌کنید، فقط effectA اجرا می‌شود. وقتی unrelated را زیاد می‌کنید، فقط effectB. این یعنی هیچ Effect بی‌دلیل اجرا نمی‌شود — یعنی Performance بالا.

خلاصه

signal = ظرف واکنش‌گرا. computed = مقدار مشتق‌شده و cache شده. effect = تابع جانبی که وابستگی‌هایش را خودکار ردیابی می‌کند. هیچ کدام به DOM وابسته نیستند — می‌توانید در Node.js هم از آن‌ها استفاده کنید.
