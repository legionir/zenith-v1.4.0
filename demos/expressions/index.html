۱. حساب پایه (Operator Precedence)

اولویت عملگرها رعایت می‌شود: ضرب قبل از جمع.

2 + 3 * 4 = (2 + 3) * 4 = 10 % 3 = 2 ** ? — اما

نکته: عملگر ** (توان) پشتیبانی نمی‌شود — می‌توانید از Math.pow یا ضرب مستقیم استفاده کنید.

۲. الحاق رشته‌ها

عملگر + هم برای عدد و هم برای رشته کار می‌کند (مثل جاوااسکریپت).

'سلام' + ' ' + $name = $name + ' ' + 'محمدی' =

۳. مقایسه و منطق

عملگرهای > < >= <= == === != !== و && || با short-circuit evaluation.

$age > 18 = $age > 18 && $age < 65 = $age >= 18 || $isActive = $age === 25 =

۴. عملگر سه‌تایی (Ternary)

شرط کوتاه: test ? valueIfTrue : valueIfFalse

$age >= 18 ? 'بزرگسال' : 'کودک' = $isActive ? 'فعال' : 'غیرفعال' =

۵. Nullish Coalescing (??)

وقتی مقدار سمت چپ null یا undefined باشد، مقدار سمت راست برگردانده می‌شود. تفاوت با ||: رشته‌ی خالی یا 0 با ?? معتبرند.

$user.nickname ?? $user.name = $user.missing ?? 'پیش‌فرض' =

در این دمو، user.nickname برابر null است پس user.name برمی‌گردد.

۶. Optional Chaining (?.)

دسترسی امن به پراپرتی‌های تو در تو. اگر هر کدام null/undefined باشد، کل عبارت undefined می‌شود (بدون خطا).

$user?.address?.city = $user?.missing?.deep =

نکته: در این فریم‌ورک، . و ?. رفتار یکسان دارند — evaluator همیشه null-safe است.

۷. فراخوانی متد (Method Call)

thisArg به‌درستی تنظیم می‌شود تا متدهای داخلی شیء کار کنند.

$user.name.toUpperCase() = $user.name.length =

۸. آرایه‌ها و Arrow Functions

آرایه‌های literal، .length، و متدهای .map، .filter با arrow functions.

[1, 2, 3].length = [1,2,3].map(x => x * 2) = [1,2,3].filter(x => x > 1) =
