۱. Counter Store — State, Getters, Actions

یک Store با defineStore('counter', { state, getters, actions }) تعریف می‌شود. State با Deep Proxy در بر می‌گیرد — پس mutations تو در تو هم reactive هستند. Getters به‌صورت Computed محاسبه می‌شوند و با تغییر State به‌روز می‌شوند.

getter doubled = getter squared = getter isEven = getter historyLast = 
const useCounterStore = defineStore('counter', {
  state: () => ({ count: 0, history: [] }),
  getters: {
    doubled:    (s) => s.count * 2,
    squared:    (s) => s.count * s.count,
    isEven:     (s) => s.count % 2 === 0,
    historyLast:(s) => s.history.at(-1) ?? '—',
  },
  actions: {
    inc() { this.state.count++; this.state.history.push('+1'); },
    dec() { this.state.count--; this.state.history.push('-1'); },
    incBy(n) { this.state.count += n; this.state.history.push(`+${n}`); },
    async asyncInc() {
      await new Promise(r => setTimeout(r, 500));
      this.state.count++;
      this.state.history.push('async +1');
    },
  },
});

۲. Deep Reactivity — Mutation تو در تو

State یک Store می‌تواند Object تو در تو داشته باشد. با Deep Proxy، تغییر یک پراپرتی عمیق (مثل state.user.preferences.theme = 'dark') هم reactive است.

۳. $patch — اعمال Partial Update

متد $patch(partial) یک آبجکت partial را روی State اعمال می‌کند. برای به‌روزرسانی چند فیلد به‌طور همزمان مفید است. 

// در Action:
patchUser() {
  userStore.$patch({
    name: 'زهرا احمدی',
    age: 30,
  });
}
// حتی nested objects هم کار می‌کنند:
patchPreferences() {
  userStore.$patch({
    preferences: { theme: 'dark', notifications: false },
  });
}

۵. Async Actions — شبیه‌سازی API Call

Action ها می‌توانند async باشند. مثلاً برای fetch از سرور و به‌روزرسانی State پس از پاسخ. در اینجا asyncInc با 500ms تاخیر، count را زیاد می‌کند.

getter historyLast آخرین آیتم history را نشان می‌دهد: 

actions: {
  async asyncInc() {
    await new Promise(r => setTimeout(r, 500));
    this.state.count++;  // mutation پس از await
    this.state.history.push('async +1');
  },
  async fetchProfile() {
    this.state.loading = true;
    const res = await fetch('/api/profile');
    const data = await res.json();
    this.state.name = data.name;  // mutation
    this.state.loading = false;
  },
}

خلاصه

        

          defineStore یک Store سراسری با Deep Reactivity می‌سازد.
          State با Proxy در بر می‌گیرد — mutation هر سطحی reactive است.
          Getters به‌صورت Computed محاسبه می‌شوند (با .get() خوانده می‌شوند).
          Actions می‌توانند async باشند و از this.state برای mutation استفاده کنند.
          $patch برای partial update، $reset برای بازگشت به initial state.
