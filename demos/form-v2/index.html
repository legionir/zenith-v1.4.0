۳. Lifecycle Hooks

رویدادهای validation: onBeforeValidate، onFieldError، onFormValid.

خلاصه

قوانین موجود: required, email, url, min, max, pattern, equals, equalsField, differentFrom, requiresField, number, integer, positive, negative, date, phone, creditCard, nationalId, persianPhone

قوانین سفارشی: defineRule(name, fn) — قوانین async: defineAsyncRule(name, fn)

Nested validation: validateForm({ address: { city: '' } }, { 'address.city': 'required' })

Lifecycle: validateWithLifecycle(values, rules, { onBeforeValidate, onAfterValidate, onFieldError, onFormValid, onFormInvalid })
