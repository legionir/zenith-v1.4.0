🖱️ Events & Modifiers

Event Delegation در سطح document + Modifier های prevent/stop/enter/shift/ctrl/self/once

delegation prevent stop enter shift+enter ctrl+click self once

📊 زنده — شمارش‌گر رویدادها

basicClick: explicitClick: handleSubmit: onEnter: onShiftEnter: onCtrlClick: onSelfClick: onOnce: onInput: onKeyup: onChange:

۱. کلیک ساده (Default Event)

zen-action="name" به‌صورت پیش‌فرض روی click تنظیم می‌شود. فقط یک Listener روی document ثبت می‌شود — حتی اگر ۱۰۰۰۰ دکمه داشته باشید.

<button zen-action="basicClick">...</button>

۲. رویداد صریح (Explicit Event)

با zen-action:click="name" صریحاً رویداد را مشخص کنید. این برای زمانی که می‌خواهید بعداً modifier اضافه کنید تمیزتر است.

<button zen-action:click="explicitClick">...</button>

۳. .prevent — جلوگیری از رفتار پیش‌فرض

روی یک <form> با zen-action:submit.prevent — بدون reload صفحه. اگر .prevent را حذف کنید، صفحه reload می‌شود.

<form zen-action:submit.prevent="handleSubmit">
  <input ...>
  <button type="submit">ثبت</button>
</form>

۴. .stop — توقف propagation

دکمه‌ی داخلی .stop دارد — وقتی کلیک می‌شود، رویداد به والد نمی‌رسد. دکمه‌ی خارجی بدون .stop است — کلیک روی آن فقط خودش را trigger می‌کند.

کلیک روی پس‌زمینه ← outerClick اجرا می‌شود
کلیک روی این ← فقط innerClick (propagation متوقف شد)

شمارش outer: — شمارش inner:

۵. .enter — فقط کلید Enter

روی keydown فیلتر می‌کند — فقط وقتی کلید Enter فشرده شود، اکشن اجرا می‌شود.

<input zen-action:keydown.enter="onEnter">

۶. .shift.enter — ترکیب Shift+Enter

چندین modifier کلیدی می‌توانند ترکیب شوند. این input فقط وقتی trigger می‌شود که Shift+Enter همزمان زده شود.

<input zen-action:keydown.shift.enter="onShiftEnter">

۷. .ctrl — کلید اصلاحی روی کلیک

این دکمه فقط وقتی اجرا می‌شود که Ctrl (یا Cmd در مک) همزمان با کلیک نگه داشته شود.

<button zen-action:click.ctrl="onCtrlClick">...</button>

۸. .self — فقط کلیک روی خود عنصر (نه فرزندان)

modifier .self در Action خودمان پیاده‌سازی شده (فریم‌ورک آن را silent نادیده می‌گیرد، ما با چک event.target === element اجرای آن را شرطی می‌کنیم). امتحان کنید: کلیک روی پس‌زمینه سبز ← اجرا می‌شود. کلیک روی فرزند زرد ← اجرا نمی‌شود.

کلیک روی این ← onSelfClick اجرا می‌شود
کلیک روی این فرزند ← اجرا نمی‌شود (target === element نادرست است) 
// در Action:
Zen.action('onSelfClick', ({ event, element }) => {
  if (event.target !== element) return;  // manual .self
  // ...
});

۹. .once — فقط یک بار اجرا شود

modifier .once نیز در Action پیاده‌سازی شده (با یک flag ساده). بعد از اولین کلیک، دیگر اجرا نمی‌شود.

تعداد دفعات اجرا: (هرگز بیشتر از ۱ نمی‌شود)

let onceFired = false;
Zen.action('onOnce', () => {
  if (onceFired) return;
  onceFired = true;
  // ...
});

۱۰. چندین رویداد روی یک عنصر

یک input می‌تواند همزمان چندین zen-action:<event> داشته باشد. در این مثال: input (هر بار تایپ)، change (وقتی blur می‌شود و مقدار عوض شده)، و keyup (هر بار رها کردن کلید).

نکته: focus و blur در bubble نمی‌شوند، پس در Event Delegation پیش‌فرض پشتیبانی نمی‌شوند. در عوض می‌توانید از keydown، keyup، input، change استفاده کنید که همگی bubble می‌شوند. 

<input
  zen-action:input="onInput"     <!-- هر بار تایپ -->
  zen-action:change="onChange"   <!-- هنگام blur با تغییر -->
  zen-action:keyup="onKeyup"     <!-- هر بار key up -->
>

هر رویداد به‌محض رخ دادن اینجا لاگ می‌شود. آخرین رویداد در پایین است.

🆕 v1.3.0 — Parameterized Actions

از v1.3.0 به بعد، می‌توانید آرگومان‌ها را مستقیماً در HTML ارسال کنید: zen-action="save($product)". آرگومان‌ها با Expression Engine ارزیابی و در ctx.args قرار می‌گیرند. این کار نیاز به getAttribute('data-id') و خواندن دستی از DOM را حذف می‌کند.

args received: calls: 
<button zen-action="addToList($product.name, $product.price)">...</button>
<button zen-action="selectProduct($product)">...</button>
<button zen-action="updateQuantity($product.id, 5)">...</button>
<button zen-action="namespace.test('hello', $product.price)">...</button>

هر بار کلیک می‌کنید، آرگومان‌های ارزیابی‌شده در ctx.args می‌آیند. اکشن namespace.test نشان می‌دهد که از v1.3.0 به بعد، نام‌ها می‌توانند شامل . برای namespacing باشند.

🆕 v1.3.0 — Event Modifier Registry

Plugin ها می‌توانند با registerEventModifier(name, handler) modifier های سفارشی تعریف کنند. اینجا یک modifier .debug ثبت کرده‌ایم که قبل از اجرای اکشن، اطلاعات رویداد را لاگ می‌کند. 

import { registerEventModifier } from '@zenith/events';

registerEventModifier('debug', (event, modifiers, element) => {
  console.log('[debug modifier]', event.type, element.tagName);
  // return false برای جلوگیری از اجرای اکشن
  return true;
});

// HTML:
// <button zen-action:click.debug="myAction">...</button>

🆕 v1.3.0 — Action Metadata & Namespace

registerAction(name, fn, metadata) متادیتای اختیاری قبول می‌کند. Zen.action.list() برای DevTools و documentation آماده است. namespace ها با . کار می‌کنند: cart.save, admin.delete. 

Zen.action('cart.save', (ctx) => { /* ... */ }, {
  description: 'ذخیره سبد خرید',
  category: 'cart',
  permissions: ['cart:write'],
});

// لیست برای DevTools:
const all = Zen.action.list();
// → [{ name: 'cart.save', metadata: { description: '...', category: 'cart' } }, ...]

🆕 v1.3.0 — Binding Cache (WeakMap)

نتایج parse کردن zen-action:* attribute ها حالا در یک WeakMap<HTMLElement, CachedBinding> کش می‌شوند. اگر attribute ها تغییر نکرده باشند، re-parse انجام نمی‌شود. این کار برای درخت‌های عمیق و صفحه‌های پویا سودمند است. وقتی attribute تغییر کند (مثلاً توسط .once)، cache خودکار invalidate می‌شود.

این feature کاملاً transparent است — هیچ تغییری در API لازم نیست. فقط performance بهتر می‌شود.

🆕 v1.3.0 — Custom Delegation Root

از v1.3.0 به بعد، می‌توانید Event Delegation را روی یک ریشه‌ی سفارشی (ShadowRoot یا HTMLElement) فعال کنید: initEventDelegation(state, { root: el.shadowRoot }). این برای Web Components و micro-frontends مفید است. 

// مستقیم:
import { initEventDelegation } from '@zenith/events';
const teardown = initEventDelegation(state, { root: myShadowRoot });

// یا از طریق Zen.start:
Zen.start(hostEl, state, { delegationRoot: hostEl.shadowRoot });

خلاصه

Event Delegation = یک Listener روی document برای هر نوع رویداد، به‌جای Listener روی هر عنصر. مزایا: Memory O(1)، کار با عناصر پویا (zen-if)، Performance بالا. Modifier ها با نقطه (.prevent, .stop, .enter, .shift, ...) زنجیره می‌شوند.
