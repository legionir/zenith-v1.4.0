👤 وضعیت کاربر (Auth)

🔒 محتوای بر اساس نقش (RBAC)

✓ مشاهده محصولات (نقش: user)
✓ افزودن محصول (products:create)
✓ ویرایش محصولات (products:edit)
✓ حذف محصولات (products:delete)
✓ پنل ادمین (نقش: admin)
✓ دسترسی کاربری (admin یا user)

💡 برای دیدن محتوای مختلف، با نقش‌های مختلف لاگین کنید. ادمین به همه دسترسی دارد.

🛒 فروشگاه محصولات (Resource + i18n + Security)

محصولات از یک Resource fetch می‌شوند (با cache). قیمت‌ها با formatPrice به تومان تبدیل می‌شوند. توضیحات با sanitizeHTML پاکسازی می‌شوند.

تعداد: ۰ cache: cold
برای بارگذاری محصولات روی دکمه کلیک کنید.

➕ افزودن محصول جدید (Form + Validation)

🛍️ سبد خرید (Store + i18n)

سبد خرید در یک Store ذخیره می‌شود (با deep reactivity). مجموع با formatPrice نمایش داده می‌شود.

آیتم: ۰ مجموع: ۰ تومان
سبد خرید خالی است.

📜 لاگ رویدادها (Effect + Scheduler)

هر تغییری در state توسط Effect ها گزارش می‌شود. Scheduler تغییرات را batch می‌کند.

🏗️ معماری این دمو

پکیج‌های استفاده‌شده:

@zenith/state        → Signal برای auth، cart، products
@zenith/runtime      → Zen.start + walker + directives
@zenith/auth         → کلاس Auth برای login/logout
@zenith/permission   → PermissionManager + zen-role/zen-permission
@zenith/store        → defineStore برای cart با deep reactivity
@zenith/i18n         → toPersianNums، formatPrice
@zenith/security     → sanitizeHTML برای توضیحات محصول
@zenith/scheduler    → batching خودکار همه effectها

جریان داده:
  User clicks login → auth.login() → auth.signal updates →
    effect runs → cart card shows (zen-if) →
    permission check → products:create button shows (zen-permission) →
    User adds product → fetch POST → cache invalidates →
    effect re-runs → product list updates →
    User adds to cart → store action → cart updates →
    cart total recomputed → DOM updates
