🎨 دایرکتیوهای DOM

دایرکتیوهای اصلی Zenith برای رندر، اتصال دوطرفه، شرط و اتصال attribute

zen-text zen-model zen-if zen-bind

۱. zen-text: رندر متن واکنش‌گرا

ساده‌ترین دایرکتیو. مقدار یک Expression را به‌صورت textContent درون عنصر قرار می‌دهد. هر بار که Signal تغییر کند، متن به‌صورت خودکار آپدیت می‌شود.

سلام ! سن شما: سال است. 

<p>سلام <span zen-text="$user.name"></span>! سن: <span zen-text="$user.age"></span></p>

۲. zen-model: اتصال دوطرفه (Two-way Binding)

با zen-model، ورودی کاربر به‌طور خودکار به Signal نوشته می‌شود و بالعکس. این همان کاری که در فریم‌ورک‌های دیگر با v-model یا ngModel انجام می‌دهید.

نام شما: — سن: 

<input type="text" zen-model="$user.name">
<input type="number" zen-model="$user.age">

۳. zen-if: رندر شرطی (Counter)

zen-if یک Expression منطقی می‌گیرد. وقتی true باشد، عنصر رندر می‌شود؛ وقتی false باشد، از DOM حذف می‌شود (نه فقط display:none).

✓ شمارنده بیشتر از ۵ است!
شمارنده ۵ یا کمتر است. 
<div zen-if="$count > 5">بیشتر از ۵</div>
<div zen-if="$count <= 5">۵ یا کمتر</div>

۴. zen-bind: اتصال Attribute

zen-bind:attr یک attribute را به Expression متصل می‌کند. برای class می‌توان از سینتکس آبجکت استفاده کرد: { className: condition }.

وضعیت پردازش: 

<button
  zen-bind:disabled="$isProcessing"
  zen-bind:class="{ primary: !$isProcessing }">
  <span zen-if="$isProcessing">در حال پردازش...</span>
  <span zen-if="!$isProcessing">کلیک کنید</span>
</button>

خلاصه

این چهار دایرکتیو پایه‌ی ساخت برنامه‌های واکنش‌گرا با Zenith هستند: zen-text برای متن، zen-model برای ورودی، zen-if برای شرط، zen-bind برای attribute. همه‌ی این‌ها به‌صورت خودکار با Signalها همگام می‌شوند — هیچ کد دستی برای آپدیت DOM لازم نیست.
