۲. Create — افزودن آیتم جدید

با resource.createOptimistic(body) آیتم فوراً به UI اضافه می‌شود (با id موقت) و در پس‌زمینه به سرور ارسال می‌شود. اگر خطا دهد، rollback می‌شود. اگر موفق شود، آیتم موقت با آیتم واقعی جایگزین می‌شود. 

const result = await resource.createOptimistic({ name, price });
// نتیجه: آیتم فوراً با id='temp-...' اضافه می‌شود،
// پس از response، با آیتم واقعی جایگزین می‌شود.

۳. Update — ویرایش آیتم

روی دکمه‌ی «ویرایش» در هر آیتم کلیک کنید. با resource.updateOptimistic(id, body) تغییرات فوراً در UI اعمال می‌شود و در پس‌زمینه به سرور ارسال می‌شود.

await resource.updateOptimistic(id, { name, price });
// اگر خطا دهد: rollback به مقدار قبلی

۴. Delete — حذف آیتم

با resource.deleteOptimistic(id) آیتم فوراً از UI حذف می‌شود و در پس‌زمینه به سرور ارسال می‌شود. در صورت خطا، آیتم برمی‌گردد.

await resource.deleteOptimistic(id);
// آیتم فوراً حذف می‌شود. اگر خطا دهد، rollback.

۵. Cache Indicator — کش یا سرور؟

وقتی list() فراخوانی می‌شود: اگر داده‌های فعلی fresh باشند (age < staleTime = ۸s)، از cache برمی‌گردند (بدون fetch). در غیر این صورت، fetch از سرور انجام می‌شود.

✓ fresh (سرور) ✓ cached (کش) ⚠ stale (در حال refresh)

۶. SWR — Stale-While-Revalidate

با resource.startAutoRefresh(interval) داده‌ها در پس‌زمینه refresh می‌شوند. الگو: داده‌ی stale فوراً نمایش داده می‌شود، سپس fetch جدید در پس‌زمینه انجام می‌شود. کاربر هیچ‌وقت صفحه‌ی خالی نمی‌بیند.

🔄 SWR فعال است. هر ۴ ثانیه در پس‌زمینه refresh می‌شود. آخرین refresh: — 
resource.startAutoRefresh(4000);  // هر 4 ثانیه
// این کار isStale=true می‌کند و list(true) صدا می‌زند.
// داده‌ی فعلی نمایش داده می‌شود، fetch در پس‌زمینه انجام می‌شود.

خلاصه

Resource یک endpoint را مدیریت می‌کند: list/read/create/update/delete. Cache، retry (فقط GET)، request dedup و optimistic update داخلی دارد. با startAutoRefresh الگوی SWR فعال می‌شود.
