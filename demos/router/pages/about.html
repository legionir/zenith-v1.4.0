ℹ️ درباره‌ی Zenith

Zenith یک فریم‌ورک واکنش‌گرا (Reactive) و پیشرو (Progressive) برای ساخت رابط‌های کاربری است.

اصول طراحی

  • Signal-based Reactivity: واکنش‌گرایی مبتنی بر Signal، نه Virtual DOM.
  • Zero Build Step: با هر static server کار می‌کند — نیازی به bundler نیست.
  • Declarative Directives: zen-text، zen-if، zen-for، zen-model، zen-bind، zen-html، zen-link، zen-route، zen-fetch و بیش از ۲۰ دایرکتیو دیگر.
  • TypeScript-Native: همه‌ی پکیج‌ها با TypeScript نوشته شده‌اند و type-safe هستند.
  • Modular Packages: ۲۹ پکیج جداگانه — فقط چیزی را import کنید که نیاز دارید.

آمار

  • ۲۹ پکیج فعال
  • ۱۰۴۷ تست پاس شده
  • ۰ خطای typecheck (با strict mode)
  • ۲۰+ دایرکتیو
