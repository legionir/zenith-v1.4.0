۱. Fade Transition

با zen-transition="fade" روی یک عنصر با zen-if، عنصر به‌جای ناپدید شدن ناگهانی، با opacity fade in/out می‌شود. کلاس‌های zen-enter-from/to و zen-leave-from/to توسط پکیج @zenith/transition اضافه/حذف می‌شوند.

عنصر مخفی است — روی دکمه کلیک کنید 
<div zen-if="$fadeVisible" zen-transition="fade">
  👋 سلام! من با fade ظاهر شدم.
</div>

<!-- CSS: -->
.fade.zen-enter-from { opacity: 0; }
.fade.zen-enter-active { transition: opacity 0.4s ease; }
.fade.zen-enter-to { opacity: 1; }
.fade.zen-leave-from { opacity: 1; }
.fade.zen-leave-active { transition: opacity 0.4s ease; }
.fade.zen-leave-to { opacity: 0; }

۳. Scale Transition

با transform: scale() و یک cubic-bezier bounce، عنصر با یک افکت فنری ظاهر/ناپدید می‌شود.

visible =
🎯 من با scale bounce می‌کنم!
عنصر مخفی است 
.scale.zen-enter-from { opacity: 0; transform: scale(0.6); }
.scale.zen-enter-active { transition: transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1); }
.scale.zen-enter-to { opacity: 1; transform: scale(1); }
/* cubic-bezier(0.34, 1.56, 0.64, 1) → افکت bounce */

۴. Custom Transition — ترکیب چند افکت

نام transition دلخواه است — هر نامی که در CSS تعریف کنید، کار می‌کند. در اینجا zen-transition="custom" از rotation + scale + blur استفاده می‌کند.

visible =
🌈 ترکیب rotation + scale + blur
عنصر مخفی است 
.custom.zen-enter-from {
  opacity: 0;
  transform: rotate(-10deg) scale(0.8);
  filter: blur(8px);
}
.custom.zen-enter-active {
  transition: opacity 0.5s, transform 0.5s, filter 0.5s;
}
.custom.zen-enter-to {
  opacity: 1; transform: rotate(0) scale(1); filter: blur(0);
}

۵. List Transitions — افزودن و حذف با انیمیشن

zen-for به‌صورت built-in از transition پشتیبانی نمی‌کند. اما می‌توان:
۱) برای enter: از CSS @keyframes روی آیتم استفاده کرد (auto-play هنگام mount).
۲) برای leave: به‌صورت دستی leaveTransition() صدا زد و بعد از اتمام انیمیشن، آیتم را از آرایه حذف کرد.

items.length =
آیتم # —

روی «افزودن آیتم» کلیک کنید — آیتم جدید با یک انیمیشن fade+slide وارد می‌شود. روی «حذف» کلیک کنید — آیتم با یک slide به راست و fade out حذف می‌شود. 

// Enter: CSS animation auto-play
@keyframes list-enter {
  from { opacity: 0; transform: translateY(-12px) scale(0.95); }
  to   { opacity: 1; transform: translateY(0) scale(1); }
}
.list-item { animation: list-enter 0.4s ...; }

// Leave: manual via leaveTransition
import { leaveTransition } from '@zenith/transition';
Zen.action('removeItem', ({ state, element }) => {
  const id = Number(element.getAttribute('data-id'));
  const node = element.closest('.list-item');
  leaveTransition(node, 'list-leave', 300, () => {
    // بعد از اتمام انیمیشن، آیتم را از آرایه حذف کن
    const items = state.items.get();
    state.items.set(items.filter(i => i.id !== id));
  });
});

۶. مقایسه: با و بدون zen-transition

دو عنصر مشابه — یکی با zen-transition="fade" و دیگری بدون آن. بدون transition، عنصر ناگهان ظاهر/ناپدید می‌شود. با transition، به‌آرامی fade می‌شود.

خلاصه

zen-transition="name" روی عنصر با zen-if باعث می‌شود به‌جای mount/unmount ناگهانی، انیمیشن CSS پخش شود. کلاس‌های zen-enter-from/to، zen-leave-from/to و zen-enter-active/zen-leave-active توسط پکیج @zenith/transition مدیریت می‌شوند. شما فقط CSS می‌نویسید — هر نام transition، هر property، هر مدت. برای list transitions، enter با CSS animation و leave با فراخوانی دستی leaveTransition() کار می‌کند.
