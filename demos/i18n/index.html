۱. تبدیل اعداد به فارسی — toPersianNums()

تابع toPersianNums(n) ارقام انگلیسی را به فارسی تبدیل می‌کند. ورودی می‌تواند عدد یا رشته باشد. این تابع به‌صورت مستقیم از State در دسترس Expression Engine قرار گرفته — پس می‌توان در zen-text استفاده کرد.

toPersianNums(123) toPersianNums(9876543210) toPersianNums($count) toPersianNums(1399 + 1)

مقدار count به‌صورت زنده فارسی می‌شود: 

import { toPersianNums } from '@zenith/i18n';
toPersianNums(123);           // "۱۲۳"
toPersianNums('price: 999');  // "price: ۹۹۹"

// در State قرار می‌دهیم تا در Expression Engine در دسترس باشد:
const state = { toPersianNums, count: signal(123) };

// در HTML:
<span zen-text="$toPersianNums($count)"></span>

۲. تاریخ شمسی — toJalali()

تابع toJalali(date) یک Date میلادی را به رشته‌ی YYYY/MM/DD شمسی تبدیل می‌کند. از تقویم جلالی استفاده می‌شود (الگوریتم استاندارد).

toJalali(new Date()) toJalali(new Date('2024-03-20')) toJalali(new Date('1979-04-01')) toJalali(new Date('2025-01-01')) 
import { toJalali } from '@zenith/i18n';
toJalali(new Date());                    // امروز به شمسی
toJalali(new Date('2024-03-20'));        // "۱۴۰۳/۰۱/۰۱" (نوروز)
toJalali(new Date('1979-04-01'));        // "۱۳۵۸/۰۱/۱۳" (انقلاب)

۳. فرمت عدد با جداکننده‌ی هزارگان — formatNumber()

تابع formatNumber(n) عدد را با جداکننده‌ی فارسی ٬ (U+066C) قالب‌بندی می‌کند و ارقام را فارسی می‌کند.

formatNumber(1234567) formatNumber(9876543210) formatNumber(0) formatNumber($price) 
formatNumber(1234567);    // "۱٬۲۳۴٬۵۶۷"
formatNumber(0);          // "۰"
formatNumber($price);     // reactive — با تغییر price آپدیت می‌شود

۴. فرمت قیمت به تومان — formatPrice()

تابع formatPrice(n) مانند formatNumber است اما " تومان" به انتهای آن اضافه می‌شود. مناسب برای نمایش قیمت در فروشگاه‌های اینترنتی ایرانی.

formatPrice(1500000) formatPrice($price) formatPrice(98000000)

قیمت فعلی محصول: 

formatPrice(1500000);   // "۱٬۵۰۰٬۰۰۰ تومان"
formatPrice($price);    // reactive

۵. ساعت زنده — با setInterval و Signal

یک Signal به نام now هر ثانیه با new Date() آپدیت می‌شود. تمام Expressionهای وابسته (ساعت، تاریخ میلادی، تاریخ شمسی) به‌صورت خودکار آپدیت می‌شوند.

📅 شمسی (جلالی)
📅 میلادی

ثانیه‌ها را ببینید! این یعنی Signal هر ثانیه set می‌شود و تمام DOM وابسته در یک flush آپدیت می‌شود. 

const now = signal(new Date());

setInterval(() => now.set(new Date()), 1000);

// در HTML:
<div class="clock" zen-text="$toPersianNums($clockTime($now))"></div>
<div zen-text="$toJalali($now)"></div>

۶. Integration با Expression Engine

همه‌ی توابع i18n می‌توانند داخل هر Expression استفاده شوند — با اپراتورها، توابع دیگر و Conditions ترکیب شوند. در این مثال، یک فرض فروشگاهی با تعداد و قیمت واحد داریم؛ قیمت کل با formatPrice نمایش داده می‌شود.

خلاصه

پکیج @zenith/i18n توابع کمکی برای فارسی‌سازی فراهم می‌کند: toPersianNums، toJalali، formatNumber، formatPrice. این توابع را در State قرار می‌دهیم تا در Expression Engine با پیشوند $ در دسترس باشند. چون Signalها reactive هستند، ترکیب با setInterval یک ساعت زنده می‌سازد.
