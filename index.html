ویژگی‌های کلیدی

یک فریم‌ورک کامل برای تولید اپلیکیشن‌های مدرن — از prototype تا production

⚡

HTML-First

منطق برنامه با directiveهای zen-* در HTML نوشته می‌شود. نه JSX، نه Template Strings. کد شما خوانا و semantic است.

🎯

Fine-grained Reactivity

مبتنی بر Signal بدون Virtual DOM. فقط کامپوننت‌های وابسته به یک Signal آپدیت می‌شوند — نه کل tree.

🔒

Security by Default

Expression Engine اختصاصی بدون eval() یا new Function(). HTML Sanitizer داخلی ضد XSS.

📦

Automatic Batching

Scheduler مبتنی بر Microtask: ۱۰۰ set متوالی → ۱ DOM Update. با Priority Queue.

🌐

Persian & RTL First

پشتیبانی داخلی از اعداد فارسی، تاریخ شمسی، فرمت قیمت تومان، و راست‌چین در همه‌جا.

🧪

TypeScript Strict

تمام ۳۱ پکیج با strict mode کامل (noUncheckedIndexedAccess، noImplicitReturns، ...).

🛠️

DevTools کامل

Chrome Extension با ۴ پنل (Signals, Timeline, Components, Effects) + VSCode Extension با autocomplete.

⚡

PWA Ready

zenith create my-app --pwa با Service Worker با ۳ استراتژی cache، manifest، و push notifications آماده.

🌐

SSR + Hydration

رندر سمت سرور با Streaming و Hydration. CSP nonce پشتیبانی می‌شود.

شروع در ۳۰ ثانیه

راه‌اندازی سریع

با CLI رسمی Zenith در چند ثانیه پروژه‌تان را بسازید

# 1. ساخت پروژه جدید $ npx @zenith/cli create my-app # 2. ورود به پوشه و نصب $ cd my-app $ npm install # 3. اجرای dev server $ npm run dev ✓ Local: http://localhost:3000/
# ساخت Progressive Web App با Service Worker و manifest $ npx @zenith/cli create my-app --pwa $ cd my-app $ npm install $ npm install -D vite-plugin-pwa workbox-window $ npm run dev # اضافه کردن آیکون‌ها به public/icons/ # اپلیکیشن قابل install روی home screen است!
# استفاده از CDN (بدون build step) $ mkdir my-app && cd my-app # ساخت index.html با import map $ cat > index.html << 'EOF' <!DOCTYPE html> <html lang="fa" dir="rtl"> <body> <span zen-text="$count"></span> <button zen-action="inc">+</button> <script type="importmap">{"imports": { "@zenith/state": "/packages/state/dist/index.js", "@zenith/runtime": "/packages/runtime/dist/index.js" }}</script> <script type="module"> import { signal } from '@zenith/state'; import { Zen } from '@zenith/runtime'; Zen.action('inc', ({state}) => state.count.set(state.count.get()+1)); Zen.start(document.body, { count: signal(0) }); </script> </body> EOF $ python3 -m http.server 3000
💡 برای static analysis فایل‌های HTML از npx @zenith/cli check ./src --strict در CI استفاده کنید.
