## ۲. تگ‌گذاری release ( Nina سطح‌ریشه)

قرارداد اعمال‌شده (مطابق رفتار گیت، نه سلیقه):
- روی `export {…} from` نام‌دار: کامنت سطح روی statement؛ اگر سطوح قاطی بود،
  statement شکافته شد (precedentScheduler/actions).
- روی `export *`: تگ روی origin (کامنت barrel نامرئی است).
- روی `export * as ns`: تگ روی statement (هر namespace جدا).
- هر overload باید level خودش را داشته باشد؛ `@deprecated` تنها هرگز طبقه‌بندی
  نمی‌کند؛ `internal` هرگز public جا زده نشد (ترکیب ناسازگار = conflicting).

پکیج‌ها (barrel/origin، همه public مگر ذکرشده):
resource، adapter-node، storage/signal، charts، icons، feature-flags، cache،
vite-plugin، auth-oauth، transition، router، shared (RegistryOwner جدا → internal)،
jalali، http، notifications (شکاف resetNotificationsInternal → internal؛
alert/confirm از origin همان public+deprecated ماندند)، errors
(core/hub/global-reset/print + leaves؛ machinery هاب:
resetErrorHubForTesting/errorHubGeneration/markErrorRouted/isErrorRouted → internal)،
auth (clearAuth در origin صادانه public+deprecated شد ZEN-DEPR-056)،
i18n (compatها از origin همان deprecated ماندند؛ __resetActiveI18n جدا → internal)،
schema (+زیرمسیرهای zod/json-schema/attr)، service-worker (sw/strategies +
networkOnly)، components (setComponentRegistryStore جدا → internal)،
ssr (render/ssg/server-component/hydrate/DEFAULTS/request-state؛
clearServerComponents در origin صادانه public+deprecated شد ZEN-DEPR-060)،
runtime (auth-api.ts + directive/context/attributes)،
zenith (index/core/browser/watch/presets + هر ۲۳ namespace).
