# ZEN-1703

> دامنه: **realtime** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-1703

## علت

پروتکل ناامن: ws:// در صفحهٔ https.

_EN:_ Insecure protocol: ws:// on an https page.

## نمونهٔ کد خطادار

```ts
import { createRealtime } from '@zenith/realtime';

// ❌ اتصال پیش از آماده بودن transport یا parser ناسازگار
const rt = createRealtime({ url: 'wss://example.test' });
rt.subscribe('room');
```

## رفع

از wss:// استفاده کنید (mixed-content).

_EN:_ Use wss:// (mixed-content).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1703');
err.code;     // 'ZEN-1703'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1703'
```
