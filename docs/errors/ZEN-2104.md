# ZEN-2104

> دامنه: **auth-oauth** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-2104

## علت

refresh منقضی.

_EN:_ Refresh expired.

## نمونهٔ کد خطادار

```ts
import { createOAuthClient } from '@zenith/auth-oauth';

// ❌ PKCE/redirect ناسازگار یا پاسخ token نامعتبر
createOAuthClient({ clientId: 'demo', redirectUri: '/callback' }).login();
```

## رفع

کاربر را مجدداً وارد کنید (re-auth)؛ refresh token را تمدید سیاست‌پذیر کنید.

_EN:_ Sign the user in again (re-auth); make refresh token renewal policy-driven.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2104');
err.code;     // 'ZEN-2104'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2104'
```
