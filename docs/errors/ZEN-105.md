# ZEN-105

> دسته: **Runtime** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-105

## علت

Directive expression evaluation failed.

ثابت کاتالوگ: `ErrorCode.RUNTIME_DIRECTIVE_EXPRESSION_FAILED`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-105 گزارش/پرتاب می‌شود
const code = ErrorCode.RUNTIME_DIRECTIVE_EXPRESSION_FAILED; // 'ZEN-105'
```

## رفع

خطای runtime/directive. ساختار DOM و نام دایرکتیو را بررسی کنید
(`zen-for` نیازمند `zen-key` و والد است؛ `zen-if` نیازمند والد). برای هر
دایرکتیو سفارشی، `defineDirective` را با `DirectiveMeta` ثبت کنید.
