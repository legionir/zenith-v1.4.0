# ZEN-9080

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9080

## علت

attribute رویدادی (on*) در template.

_EN:_ Event attribute (on*) in template.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

از zen-click/zen-action (event delegation امن) استفاده کنید (جایگزین Z800 قدیمی).

_EN:_ Use zen-click/zen-action (safe event delegation) (replaces legacy Z800).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9080');
err.code;     // 'ZEN-9080'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9080'
```
