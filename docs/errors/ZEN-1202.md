# ZEN-1202

> دامنه: **cache** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1202

## علت

loader کش شکست خورد.

_EN:_ Cache loader failed.

## نمونهٔ کد خطادار

```ts
import { createCache } from '@zenith/cache';

// ❌ ttl نامعتبر (منفی/غیرعدد) یا شکست loader
const cache = createCache({ ttl: -1 });
```

## رفع

خطای اصلی در cause است؛ retry یا fallback را بررسی کنید.

_EN:_ See cause for the original error; check retry/fallback.
