# ZEN-2002

> دامنه: **theme** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2002

## علت

ذخیره‌گاه تم در دسترس نیست.

_EN:_ Theme storage unavailable.

## نمونهٔ کد خطادار

```ts
import { createTheme } from '@zenith/theme';

// ❌ توکن رنگ ناشناخته در تم ارسال شده است
createTheme({ colors: { '--zen-brand': 'var(--missing)' } });
```

## رفع

storage تم را memory یا جایگزین قرار دهید.

_EN:_ Use the memory storage or an alternative for theme.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2002');
err.code;     // 'ZEN-2002'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2002'
```
