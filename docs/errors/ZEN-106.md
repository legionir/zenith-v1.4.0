# ZEN-106

> دسته: **Runtime** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-106

## علت

Component not found in the registry.

ثابت کاتالوگ: `ErrorCode.RUNTIME_COMPONENT_NOT_FOUND`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-106 گزارش/پرتاب می‌شود
const code = ErrorCode.RUNTIME_COMPONENT_NOT_FOUND; // 'ZEN-106'
```

## رفع

خطای runtime/directive. ساختار DOM و نام دایرکتیو را بررسی کنید
(`zen-for` نیازمند `zen-key` و والد است؛ `zen-if` نیازمند والد). برای هر
دایرکتیو سفارشی، `defineDirective` را با `DirectiveMeta` ثبت کنید.
