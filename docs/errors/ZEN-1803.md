# ZEN-1803

> دامنه: **adapters** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1803

## علت

AsyncLocalStorage در این runtime در دسترس نیست.

_EN:_ AsyncLocalStorage unavailable in this runtime.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

context صریح (domImpl/ALS-free مسیر #92) را فعال کنید (DEC-022).

_EN:_ Enable the explicit context (domImpl/ALS-free path #92) (DEC-022).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1803');
err.code;     // 'ZEN-1803'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1803'
```
