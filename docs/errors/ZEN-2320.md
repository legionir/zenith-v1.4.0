# ZEN-2320

> دامنه: **runtime-core** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2320

## علت

نسخهٔ پکیج‌ها lockstep نیست (assertCompatible).

_EN:_ Package versions not in lockstep (assertCompatible).

## نمونهٔ کد خطادار

```ts
import { defineDirective } from '@zenith/runtime-core';

// ❌ دایرکتیو با امضای نادرست یا bind بدون Cleanup ثبت شده است
defineDirective({ name: 'bad', bind: () => undefined });
```

## رفع

همهٔ @zenith/* را به یک نسخه (DEC-026) برسانید؛ نسخه‌های مشاهده‌شده در details است.

_EN:_ All @zenith/* packages must share one version; run npm ls @zenith.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2320');
err.code;     // 'ZEN-2320'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2320'
```
