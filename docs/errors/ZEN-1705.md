# ZEN-1705

> دامنه: **realtime** • دسته: **Network** • لینک آنلاین: https://zenith.dev/errors/ZEN-1705

## علت

heartbeat timeout.

_EN:_ Heartbeat timeout.

## نمونهٔ کد خطادار

```ts
import { createRealtime } from '@zenith/realtime';

// ❌ اتصال پیش از آماده بودن transport یا parser ناسازگار
const rt = createRealtime({ url: 'wss://example.test' });
rt.subscribe('room');
```

## رفع

heartbeatInterval سرویس و اتصال را بررسی کنید؛ reconnect خودکار آغاز می‌شود.

_EN:_ Check the service heartbeatInterval and the connection; auto reconnect starts.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1705');
err.code;     // 'ZEN-1705'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1705'
```
