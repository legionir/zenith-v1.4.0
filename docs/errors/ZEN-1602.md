# ZEN-1602

> دامنه: **ui** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1602

## علت

zen-tab بدون zen-tabpanel متناظر.

_EN:_ zen-tab without a matching zen-tabpanel.

## نمونهٔ کد خطادار

```ts
import { createSelect } from '@zenith/ui';

// ❌ مقدار انتخاب‌شده در فهرست options نیست و placeholder هم مجاز نشده
createSelect({ options: [{ value: 'a' }], value: 'b' });
```

## رفع

برای هر tab یک panel با aria-controls هم‌نام بگذارید.

_EN:_ Give every tab a panel with a matching aria-controls.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1602');
err.code;     // 'ZEN-1602'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1602'
```
