# ZEN-2530

> دامنه: **tooling** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2530

## علت

درخواست بدون handler (mock).

_EN:_ Request without handler (mock).

## نمونهٔ کد خطادار

```ts
import { compileTemplate } from '@zenith/compiler';

// ❌ خطای ابزار build (کامپایل/اسکن/emit) — جزئیات در details
compileTemplate('<div zen-if=""></div>');
```

## رفع

handler متناظر ثبت یا onUnhandledRequest را bypass کنید؛ مسیر/متد در details است.

_EN:_ Register the matching handler or set onUnhandledRequest to bypass; path/method in details.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

err.code;     // 'ZEN-2530'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2530'
```
