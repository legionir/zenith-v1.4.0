# ZEN-1812

> دامنه: **adapters** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1812

## علت

DOM implementation نصب نیست.

_EN:_ DOM implementation not installed.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

linkedom یا happy-dom را به‌عنوان dependency نصب کنید (domImpl).

_EN:_ Install linkedom or happy-dom as a dependency (domImpl).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1812');
err.code;     // 'ZEN-1812'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1812'
```
