# ZEN-1314

> دامنه: **i18n** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1314

## علت

بارگذاری پیام‌ها شکست خورد.

_EN:_ Loading messages failed.

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

مسیر loader و شبکه را بررسی کنید؛ خطای اصلی در cause است.

_EN:_ Check the loader path and network; the original error is in cause.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1314');
err.code;     // 'ZEN-1314'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1314'
```
