# ZEN-2101

> دامنه: **auth-oauth** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-2101

## علت

state مطابق نیست (احتمال CSRF).

_EN:_ state mismatch (possible CSRF).

## نمونهٔ کد خطادار

```ts
import { createOAuthClient } from '@zenith/auth-oauth';

// ❌ code_verifier در callback با verifier ذخیره‌شدهٔ PKCE نمی‌خواند
client.handleCallback(new URL(location.href));
```

## رفع

flow را از همان مرورگر/تب ادامه دهید؛ state یک‌بارمصرف است (RFC 6749 §10.12).

_EN:_ Continue the flow from the same browser/tab; state is single-use (RFC 6749 §10.12).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2101');
err.code;     // 'ZEN-2101'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2101'
```
