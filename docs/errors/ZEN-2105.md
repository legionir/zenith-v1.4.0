# ZEN-2105

> دامنه: **auth-oauth** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-2105

## علت

callback بدون code.

_EN:_ Callback without code.

## نمونهٔ کد خطادار

```ts
import { createOAuthClient } from '@zenith/auth-oauth';

// ❌ PKCE/redirect ناسازگار یا پاسخ token نامعتبر
createOAuthClient({ clientId: 'demo', redirectUri: '/callback' }).login();
```

## رفع

response_type=code را در authorize بگذارید؛ error را از query parse کنید.

_EN:_ Set response_type=code in authorize; parse error from the query.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2105');
err.code;     // 'ZEN-2105'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2105'
```
