# ZEN-9031

> دامنه: **cli** • دسته: **Compiler** • لینک آنلاین: https://zenith.dev/errors/ZEN-9031

## علت

zen-text با عبارت خالی.

_EN:_ zen-text with an empty expression.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

عبارت معتبر بدهید یا directive را حذف کنید (جایگزین Z301 قدیمی).

_EN:_ Provide a valid expression or remove the directive (replaces legacy Z301).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9031');
err.code;     // 'ZEN-9031'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9031'
```
