# ZEN-1603

> دامنه: **ui** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1603

## علت

مقدار value خارج از گزینه‌ها.

_EN:_ Value outside the options.

## نمونهٔ کد خطادار

```ts
import { createSelect } from '@zenith/ui';

// ❌ مقدار انتخاب‌شده در فهرست options نیست و placeholder هم مجاز نشده
createSelect({ options: [{ value: 'a' }], value: 'b' });
```

## رفع

value باید یکی از مقادیر options باشد (یا placeholder مجاز است).

_EN:_ value must be one of the options (or the allowed placeholder).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1603');
err.code;     // 'ZEN-1603'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1603'
```
