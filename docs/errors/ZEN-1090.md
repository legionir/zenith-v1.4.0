# ZEN-1090

> دامنه: **schema** • دسته: **Internal** • لینک آنلاین: https://zenith.dev/errors/ZEN-1090

## علت

آرگومان نامعتبر به تابع اعتبارسنجی گزینه‌ها.

_EN:_ Invalid argument to option validation function.

## نمونهٔ کد خطادار

```ts
import { s, validateOptions } from '@zenith/schema';

// ❌ مقدار ارسال‌شده با schema نمی‌خواند (یا کلید ناشناخته است)
validateOptions({ ttl: 'soon' }, s.object({ ttl: s.number() }));
```

## رفع

امضای تابع را از مستندات schema ببینید؛ آرگومان دوم باید schema معتبر باشد.

_EN:_ See the schema docs for the function signature; the second argument must be a valid schema.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1090');
err.code;     // 'ZEN-1090'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1090'
```
