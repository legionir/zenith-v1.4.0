# ZEN-1801

> دامنه: **adapters** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1801

## علت

رندر SSR با timeout متوقف شد.

_EN:_ SSR render stopped by timeout.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

renderTimeoutMs را افزایش یا داده‌های کندِ path را به suspense ببرید.

_EN:_ Increase renderTimeoutMs or move slow path data into suspense.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1801');
err.code;     // 'ZEN-1801'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1801'
```
