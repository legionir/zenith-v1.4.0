# ZEN-2102

> دامنه: **auth-oauth** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-2102

## علت

id_token نامعتبر.

_EN:_ Invalid id_token.

## نمونهٔ کد خطادار

```ts
import { createOAuthClient } from '@zenith/auth-oauth';

// ❌ PKCE/redirect ناسازگار یا پاسخ token نامعتبر
createOAuthClient({ clientId: 'demo', redirectUri: '/callback' }).login();
```

## رفع

issuer/audience و امضا (JWKS) را بررسی کنید.

_EN:_ Check issuer/audience and the (JWKS) signature.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2102');
err.code;     // 'ZEN-2102'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2102'
```
