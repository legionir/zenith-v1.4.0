# ZEN-005

> دسته: **Expression** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-005

## علت

The expression is not a function.

ثابت کاتالوگ: `ErrorCode.EXPRESSION_NOT_A_FUNCTION`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-005 گزارش/پرتاب می‌شود
const code = ErrorCode.EXPRESSION_NOT_A_FUNCTION; // 'ZEN-005'
```

## رفع

خطای ارزیابی عبارت (Expression/Validator). ورودی کاربر یا context را با
`@zenith/expressions` بسنجید؛ مقادیر مجاز را در `Zen.start(..., { context })` بدهید
و از `parse()`/validator قبل از اجرا استفاده کنید.
