# ZEN-2303

> دامنه: **runtime-core** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-2303

## علت

zen-for بدون zen-key.

_EN:_ zen-for without zen-key.

## نمونهٔ کد خطادار

```ts
import { defineDirective } from '@zenith/runtime-core';

// ❌ دایرکتیو با امضای نادرست یا bind بدون Cleanup ثبت شده است
defineDirective({ name: 'bad', bind: () => undefined });
```

## رفع

zen-key یکتا و پایدار برای هر آیتم بگذارید (همان ZEN-101؛ برای API جدید core).

_EN:_ Give each item a unique stable zen-key (same as ZEN-101; for the new core API).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2303');
err.code;     // 'ZEN-2303'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2303'
```
