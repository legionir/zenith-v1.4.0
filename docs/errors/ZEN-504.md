# ZEN-504

> دسته: **Compiler** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-504

## علت

Missing import at compile time.

ثابت کاتالوگ: `ErrorCode.COMPILE_MISSING_IMPORT`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-504 گزارش/پرتاب می‌شود
const code = ErrorCode.COMPILE_MISSING_IMPORT; // 'ZEN-504'
```

## رفع

خطای کامپایل. نام دایرکتیو را تصحیح کنید، importهای موردنیاز قالب را
به کامپایلر بدهید و خطای عبارت را پیش از build برطرف کنید.
