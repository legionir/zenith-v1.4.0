# ZEN-2302

> دامنه: **runtime-core** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-2302

## علت

تعارض directive ساختاری روی یک المان.

_EN:_ Conflicting structural directives on one element.

## نمونهٔ کد خطادار

```ts
import { defineDirective } from '@zenith/runtime-core';

// ❌ دایرکتیو با امضای نادرست یا bind بدون Cleanup ثبت شده است
defineDirective({ name: 'bad', bind: () => undefined });
```

## رفع

zen-if و zen-for (و همتایان else) را روی المان‌های جدا بگذارید (SPEC §۲.۸ priority).

_EN:_ Keep only one of zen-if/zen-for/zen-switch/and similar per element.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2302');
err.code;     // 'ZEN-2302'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2302'
```
