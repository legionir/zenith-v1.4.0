# ZEN-2201

> دامنه: **feature-flags** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2201

## علت

پرچم تعریف نشده (فقط dev).

_EN:_ Flag not defined (dev only).

## نمونهٔ کد خطادار

```ts
import { rollout } from '@zenith/feature-flags';

// ❌ قاعدهٔ rollout با درصد/بازهٔ نامعتبر تعریف شده است
rollout('beta', { percentage: 150 });
```

## رفع

flag را در registry ثبت کنید؛ در prod مقدار default مصرف می‌شود.

_EN:_ Register the flag in the registry; in prod the default value is used.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2201');
err.code;     // 'ZEN-2201'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2201'
```
