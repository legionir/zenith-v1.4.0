# ZEN-403

> دسته: **Security** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-403

## علت

Secure random source unavailable.

ثابت کاتالوگ: `ErrorCode.SECURITY_RANDOM_SOURCE_UNAVAILABLE`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-403 گزارش/پرتاب می‌شود
const code = ErrorCode.SECURITY_RANDOM_SOURCE_UNAVAILABLE; // 'ZEN-403'
```

## رفع

خطای امنیتی. ورودی غیرقابل‌اعتماد را sanitize کنید (`@zenith/security`)،
نام ویژگی/شناسه‌های ممنوع را در عبارت‌ها به‌کار نبرید و از CSPRNG
(`secureId`) برای شناسه‌های امنیتی استفاده کنید.
