# ZEN-1501

> دامنه: **head** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1501

## علت

تگ مجاز نیست.

_EN:_ Tag not allowed.

## نمونهٔ کد خطادار

```ts
import { setHead } from '@zenith/head';

// ❌ تگ بدنه (عنصر div) در head مجاز نیست
setHead({ title: 'Zenith', tags: ['<div>body markup</div>'] });
```

## رفع

فهرست allowlist §head را ببینید؛ تگ‌های بدنه در head ممنوع‌اند.

_EN:_ See the §head allowlist; body tags are forbidden in head.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1501');
err.code;     // 'ZEN-1501'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1501'
```
