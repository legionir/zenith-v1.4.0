# ZEN-001

> دسته: **Expression** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-001

## علت

Variable is not defined in the context.

ثابت کاتالوگ: `ErrorCode.EXPRESSION_VARIABLE_NOT_DEFINED`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-001 گزارش/پرتاب می‌شود
const code = ErrorCode.EXPRESSION_VARIABLE_NOT_DEFINED; // 'ZEN-001'
```

## رفع

خطای ارزیابی عبارت (Expression/Validator). ورودی کاربر یا context را با
`@zenith/expressions` بسنجید؛ مقادیر مجاز را در `Zen.start(..., { context })` بدهید
و از `parse()`/validator قبل از اجرا استفاده کنید.
