# ZEN-1901

> دامنه: **analytics** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1901

## علت

ارائه‌دهندهٔ آنالیتیکس شکست خورد (خطا بلعیده نمی‌شود؛ جدا از برنامه گزارش شد).

_EN:_ Analytics provider failed (error not swallowed; reported separately).

## نمونهٔ کد خطادار

```ts
import { createAnalytics } from '@zenith/runtime';

// A provider rejection is isolated and reported as ZEN-1901 via @zenith/logger.
// Raw errors, event props and identifiers are deliberately not forwarded.
const analytics = createAnalytics({
  consent: { default: true },
  respectDNT: false,
  providers: [{ name: 'failing-demo', send: async () => { throw new Error('provider offline'); } }],
});
analytics.track('demo');
analytics.dispose();
```

## رفع

provider را بررسی یا موقتاً غیرفعال کنید؛ دادهٔ رویداد و خطای اصلی برای حفظ حریم خصوصی گزارش نمی‌شوند.

_EN:_ Check or temporarily disable the provider; event data and the original error are omitted for privacy.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1901');
err.code;     // 'ZEN-1901'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1901'
```
