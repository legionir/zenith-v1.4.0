# ZEN-1604

> دامنه: **ui** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1604

## علت

portal مقصد ندارد.

_EN:_ Portal has no target.

## نمونهٔ کد خطادار

```ts
import { createSelect } from '@zenith/ui';

// ❌ مقدار انتخاب‌شده در فهرست options نیست و placeholder هم مجاز نشده
createSelect({ options: [{ value: 'a' }], value: 'b' });
```

## رفع

target portal باید به المان موجود در DOM اشاره کند.

_EN:_ The portal target must point to an element present in the DOM.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1604');
err.code;     // 'ZEN-1604'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1604'
```
