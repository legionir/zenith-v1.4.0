# ZEN-2310

> دامنه: **runtime-core** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2310

## علت

عدم تطابق hydration.

_EN:_ Hydration mismatch.

## نمونهٔ کد خطادار

```ts
import { defineDirective } from '@zenith/runtime-core';

// ❌ دایرکتیو با امضای نادرست یا bind بدون Cleanup ثبت شده است
defineDirective({ name: 'bad', bind: () => undefined });
```

## رفع

در dev diff چاپ می‌شود؛ در prod بازرندر موضعی انجام می‌گیرد. خروجی SSR/client را یکسان کنید.

_EN:_ Server and client must render identical markup; check data and markers.
