# ZEN-1822

> دامنه: **adapters** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1822

## علت

داده در زمان build در دسترس نیست.

_EN:_ Data unavailable at build time.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

منبع داده را در build stage در دسترس کنید یا مسیر را CSR/ISR کنید.

_EN:_ Make the data source available during build or mark the route CSR/ISR.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1822');
err.code;     // 'ZEN-1822'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1822'
```
