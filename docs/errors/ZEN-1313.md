# ZEN-1313

> دامنه: **i18n** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1313

## علت

locale پشتیبانی‌نشده.

_EN:_ Unsupported locale.

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

locale را در فهرست fallback ثبت کنید یا bundle آن را بارگذاری کنید.

_EN:_ Register the locale in the fallback list or load its bundle.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1313');
err.code;     // 'ZEN-1313'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1313'
```
