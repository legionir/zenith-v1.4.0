# ZEN-401

> دسته: **Security** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-401

## علت

XSS blocked: untrusted markup neutralized.

ثابت کاتالوگ: `ErrorCode.SECURITY_XSS_BLOCKED`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-401 گزارش/پرتاب می‌شود
const code = ErrorCode.SECURITY_XSS_BLOCKED; // 'ZEN-401'
```

## رفع

خطای امنیتی. ورودی غیرقابل‌اعتماد را sanitize کنید (`@zenith/security`)،
نام ویژگی/شناسه‌های ممنوع را در عبارت‌ها به‌کار نبرید و از CSPRNG
(`secureId`) برای شناسه‌های امنیتی استفاده کنید.
