# ZEN-1502

> دامنه: **head** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1502

## علت

JSON-LD نامعتبر.

_EN:_ Invalid JSON-LD.

## نمونهٔ کد خطادار

```ts
import { setHead } from '@zenith/head';

// ❌ تگ بدنه (عنصر div) در head مجاز نیست
setHead({ title: 'Zenith', tags: ['<div>body markup</div>'] });
```

## رفع

object را با JSON.stringify serializable کنید و schema.org را بررسی نمایید.

_EN:_ Serialize the object with JSON.stringify and check schema.org.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1502');
err.code;     // 'ZEN-1502'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1502'
```
