# ZEN-1303

> دامنه: **i18n** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1303

## علت

تاریخ نامعتبر (وجود ندارد).

_EN:_ Invalid date (does not exist).

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

روز/ماه را بررسی کنید (مثلاً ۱۵ اسفند ۳۰ روز نیست).

_EN:_ Check day/month (e.g. Esfand 30 does not have 31).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1303');
err.code;     // 'ZEN-1303'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1303'
```
