# ZEN-1403

> دامنه: **a11y** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1403

## علت

ویژگی aria-* با نقش المان ناسازگار است.

_EN:_ aria-* attribute incompatible with the element role.

## نمونهٔ کد خطادار

```ts
import { createFocusTrap } from '@zenith/a11y';

// ❌ ناحیهٔ trap هیچ المان focusable ندارد
const trap = createFocusTrap(document.querySelector('#empty-panel'));
trap.activate();
```

## رفع

ترکیب role/aria را با WAI-ARIA ARIA in HTML تطبیق دهید.

_EN:_ Match role/aria with WAI-ARIA (ARIA in HTML).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1403');
err.code;     // 'ZEN-1403'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1403'
```
