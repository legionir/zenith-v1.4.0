# ZEN-1902

> دامنه: **analytics** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-1902

## علت

رضایت کاربر لازم است.

_EN:_ User consent required.

## نمونهٔ کد خطادار

```ts
import { createAnalytics } from '@zenith/analytics';

// ❌ provider ثبت‌نشده یا رویداد ناشناخته ارسال شده است
const analytics = createAnalytics();
analytics.track('unknown_event');
```

## رفع

قبل از track، consent manager را فعال کنید (GDPR).

_EN:_ Enable the consent manager before tracking (GDPR).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1902');
err.code;     // 'ZEN-1902'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1902'
```
