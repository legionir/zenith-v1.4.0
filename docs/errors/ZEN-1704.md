# ZEN-1704

> دامنه: **realtime** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1704

## علت

صف ارسال پر است.

_EN:_ Send queue full.

## نمونهٔ کد خطادار

```ts
import { createRealtime } from '@zenith/realtime';

// ❌ اتصال پیش از آماده بودن transport یا parser ناسازگار
const rt = createRealtime({ url: 'wss://example.test' });
rt.subscribe('room');
```

## رفع

نرخ ارسال را کم یا maxQueueSize را افزایش دهید؛ پیام‌های drop‌شده در details‌اند.

_EN:_ Reduce send rate or raise maxQueueSize; dropped messages are in details.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1704');
err.code;     // 'ZEN-1704'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1704'
```
