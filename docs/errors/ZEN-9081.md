# ZEN-9081

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9081

## علت

iframe بدون sandbox.

_EN:_ iframe without sandbox.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

sandbox محدودکننده برای iframe بگذارید (جایگزین Z810 قدیمی).

_EN:_ Add a restrictive sandbox to the iframe (replaces legacy Z810).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9081');
err.code;     // 'ZEN-9081'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9081'
```
