# ZEN-9001

> دامنه: **cli** • دسته: **Internal** • لینک آنلاین: https://zenith.dev/errors/ZEN-9001

## علت

خواندن فایل ممکن نیست (check).

_EN:_ Unable to read file (check).

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

مجوز/مسیر فایل را بررسی کنید (جایگزین Z001 قدیمی).

_EN:_ Check file permissions/path (replaces legacy Z001).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9001');
err.code;     // 'ZEN-9001'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9001'
```
