# ZEN-9032

> دامنه: **cli** • دسته: **Compiler** • لینک آنلاین: https://zenith.dev/errors/ZEN-9032

## علت

zen-if با عبارت خالی.

_EN:_ zen-if with an empty expression.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

عبارت شرطی معتبر بدهید (جایگزین Z302 قدیمی).

_EN:_ Provide a valid conditional expression (replaces legacy Z302).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9032');
err.code;     // 'ZEN-9032'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9032'
```
