# ZEN-201

> دسته: **Resource** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-201

## علت

Resource has been destroyed.

ثابت کاتالوگ: `ErrorCode.RESOURCE_DESTROYED`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-201 گزارش/پرتاب می‌شود
const code = ErrorCode.RESOURCE_DESTROYED; // 'ZEN-201'
```

## رفع

خطای Resource. در دسترس بودن endpoint، وضعیت HTTP و ترتیب
`fetch`/`dispose` را بررسی کنید؛ از `Resource.get()` پس از `dispose()` استفاده نکنید.
