# ZEN-9061

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9061

## علت

referrer ضعیف در head.

_EN:_ Weak referrer policy in head.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

referrerpolicy را no-referrer یا strict-origin-when-cross-origin کنید (جایگزین Z601 قدیمی).

_EN:_ Set referrerpolicy to no-referrer or strict-origin-when-cross-origin (replaces legacy Z601).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9061');
err.code;     // 'ZEN-9061'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9061'
```
