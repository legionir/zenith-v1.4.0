# ZEN-2401

> دامنه: **devtools-core** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2401

## علت

نسخهٔ hook ناسازگار.

_EN:_ Incompatible hook version.

## نمونهٔ کد خطادار

```ts
import { registerSignal } from '@zenith/devtools-core';

// ❌ شناسه/ثبت تکراری یا سرریز تاریخچه در devtools-core
registerSignal('id');
```

## رفع

devtools و runtime را هم‌نسخه کنید (lockstep، DEC-026).

_EN:_ Keep devtools and runtime on the same version (lockstep, DEC-026).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2401');
err.code;     // 'ZEN-2401'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2401'
```
