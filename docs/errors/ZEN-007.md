# ZEN-007

> دسته: **Expression** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-007

## علت

Unknown node type in the expression AST.

ثابت کاتالوگ: `ErrorCode.EXPRESSION_UNKNOWN_NODE_TYPE`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-007 گزارش/پرتاب می‌شود

```

## رفع

خطای ارزیابی عبارت (Expression/Validator). ورودی کاربر یا context را با
`@zenith/expressions` بسنجید؛ مقادیر مجاز را در `Zen.start(..., { context })` بدهید
و از `parse()`/validator قبل از اجرا استفاده کنید.
