# ZEN-1311

> دامنه: **i18n** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1311

## علت

کلید پیام پیدا نشد.

_EN:_ Message key not found.

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

کلید را به bundle اضافه کنید یا missing策略 (throw/warn/empty) را تغییر دهید.

_EN:_ Add the key to the bundle or change the missing policy (throw/warn/empty).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1311');
err.code;     // 'ZEN-1311'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1311'
```
