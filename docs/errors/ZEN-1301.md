# ZEN-1301

> دامنه: **i18n** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1301

## علت

تاریخ خارج از بازهٔ پشتیبانی‌شدهٔ تقویم جلالی است.

_EN:_ Date outside the supported Jalali calendar range.

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

بازهٔ مجاز ۱۲۰۱..۱۵۰۰ هجری شمسی است (DEC-020: به‌جای هشدار، throw).

_EN:_ Allowed range is 1201..1500 SH (DEC-020: throw instead of warn).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1301');
err.code;     // 'ZEN-1301'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1301'
```
