# ZEN-1811

> دامنه: **adapters** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1811

## علت

runtime پشتیبانی نمی‌شود.

_EN:_ Unsupported runtime.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

Node ≥18.19، Cloudflare Workers یا Deno (DEC-027) را انتخاب کنید.

_EN:_ Choose Node >=18.19, Cloudflare Workers or Deno (DEC-027).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1811');
err.code;     // 'ZEN-1811'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1811'
```
