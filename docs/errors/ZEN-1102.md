# ZEN-1102

> دامنه: **storage** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1102

## علت

سهمیهٔ ذخیره‌گاه پر است (quota).

_EN:_ Storage quota exceeded.

## نمونهٔ کد خطادار

```ts
import { createStorage } from '@zenith/storage';

// ❌ در حالت private مرورگر یا پر شدن سهمیه، ذخیره‌سازی محلی در دسترس نیست
const store = createStorage({ driver: 'local' });
store.set('profile', 'x'.repeat(6_000_000)); // → quota
```

## رفع

کلیدهای قدیمی را پاک کنید یا از IndexedDB adapter استفاده کنید.

_EN:_ Prune old keys or switch to the IndexedDB adapter.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1102');
err.code;     // 'ZEN-1102'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1102'
```
