# ZEN-1302

> دامنه: **i18n** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1302

## علت

قالب تاریخ نامعتبر.

_EN:_ Invalid date format.

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

توکن‌های مجاز: YYYY YY MM M DD D MMM MMMM؛ ترکیب ناشناخته را حذف کنید.

_EN:_ Allowed tokens: YYYY YY MM M DD D MMM MMMM; remove unknown combinations.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1302');
err.code;     // 'ZEN-1302'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1302'
```
