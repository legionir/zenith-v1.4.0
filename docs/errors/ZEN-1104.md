# ZEN-1104

> دامنه: **storage** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1104

## علت

دادهٔ ذخیره‌شده خراب/غیرقابل‌تجزیه است.

_EN:_ Stored data is corrupt/unparseable.

## نمونهٔ کد خطادار

```ts
import { createStorage } from '@zenith/storage';

// ❌ در حالت private مرورگر یا پر شدن سهمیه، ذخیره‌سازی محلی در دسترس نیست
const store = createStorage({ driver: 'local' });
store.set('profile', 'x'.repeat(6_000_000)); // → quota
```

## رفع

کلید آسیب‌دیده حذف می‌شود؛ منبع داده را بازسازی کنید.

_EN:_ The corrupt key is removed; rebuild the data source.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1104');
err.code;     // 'ZEN-1104'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1104'
```
