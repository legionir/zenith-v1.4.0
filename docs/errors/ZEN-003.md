# ZEN-003

> دسته: **Expression** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-003

## علت

Forbidden identifier in the expression (security).

ثابت کاتالوگ: `ErrorCode.EXPRESSION_SECURITY_FORBIDDEN_IDENTIFIER`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-003 گزارش/پرتاب می‌شود
const code = ErrorCode.EXPRESSION_SECURITY_FORBIDDEN_IDENTIFIER; // 'ZEN-003'
```

## رفع

خطای ارزیابی عبارت (Expression/Validator). ورودی کاربر یا context را با
`@zenith/expressions` بسنجید؛ مقادیر مجاز را در `Zen.start(..., { context })` بدهید
و از `parse()`/validator قبل از اجرا استفاده کنید.
