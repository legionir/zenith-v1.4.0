# ZEN-1004

> دامنه: **schema** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1004

## علت

مقدار خارج از بازهٔ مجاز.

_EN:_ Value out of allowed range.

## نمونهٔ کد خطادار

```ts
import { s, validateOptions } from '@zenith/schema';

// ❌ مقدار ارسال‌شده با schema نمی‌خواند (یا کلید ناشناخته است)
validateOptions({ ttl: 'soon' }, s.object({ ttl: s.number() }));
```

## رفع

مقدار را بین کمینه و بیشینهٔ اعلام‌شده در details قرار دهید.

_EN:_ Keep the value between the min/max declared in details.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1004');
err.code;     // 'ZEN-1004'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1004'
```
