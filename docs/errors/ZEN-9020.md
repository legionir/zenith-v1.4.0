# ZEN-9020

> دامنه: **cli** • دسته: **Compiler** • لینک آنلاین: https://zenith.dev/errors/ZEN-9020

## علت

directive منسوخ‌شده.

_EN:_ Deprecated directive.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

جایگزین رسمی را طبق جدول DEPRECATED_DIRECTIVES به‌کار ببرید (جایگزین Z200 قدیمی).

_EN:_ Use the official replacement per DEPRECATED_DIRECTIVES (replaces legacy Z200).
