# ZEN-104

> دسته: **Runtime** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-104

## علت

zen-if element has no parent.

ثابت کاتالوگ: `ErrorCode.RUNTIME_ZEN_IF_NO_PARENT`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-104 گزارش/پرتاب می‌شود
const code = ErrorCode.RUNTIME_ZEN_IF_NO_PARENT; // 'ZEN-104'
```

## رفع

خطای runtime/directive. ساختار DOM و نام دایرکتیو را بررسی کنید
(`zen-for` نیازمند `zen-key` و والد است؛ `zen-if` نیازمند والد). برای هر
دایرکتیو سفارشی، `defineDirective` را با `DirectiveMeta` ثبت کنید.
