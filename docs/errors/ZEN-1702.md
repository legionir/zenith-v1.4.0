# ZEN-1702

> دامنه: **realtime** • دسته: **Network** • لینک آنلاین: https://zenith.dev/errors/ZEN-1702

## علت

پیام نامعتبر (parse شکست).

_EN:_ Invalid message (parse failed).

## نمونهٔ کد خطادار

```ts
import { createRealtime } from '@zenith/realtime';

// ❌ اتصال پیش از آماده بودن transport یا parser ناسازگار
const rt = createRealtime({ url: 'wss://example.test' });
rt.subscribe('room');
```

## رفع

فرمت پیام (default: JSON) را با parser سرویس تطبیق دهید.

_EN:_ Match the message format (default: JSON) with the service parser.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1702');
err.code;     // 'ZEN-1702'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1702'
```
