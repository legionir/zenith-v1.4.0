# ZEN-9040

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9040

## علت

zen-html با متغیر قابل‌تزریق احتمالی.

_EN:_ zen-html with a probably injectable variable.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

ورودی را sanitizeHTML کنید یا allowlist پیش‌فرض را حفظ کنید (جایگزین Z400 قدیمی).

_EN:_ Sanitize input with sanitizeHTML or keep the default allowlist (replaces legacy Z400).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9040');
err.code;     // 'ZEN-9040'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9040'
```
