# ZEN-1503

> دامنه: **head** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1503

## علت

تعداد تگ‌ها از maxTags بیشتر شد.

_EN:_ Tag count exceeded maxTags.

## نمونهٔ کد خطادار

```ts
import { setHead } from '@zenith/head';

// ❌ تگ بدنه (عنصر div) در head مجاز نیست
setHead({ title: 'Zenith', tags: ['<div>body markup</div>'] });
```

## رفع

تگ‌ها را ادغام کنید یا maxTags را آگاهانه افزایش دهید.

_EN:_ Merge tags or knowingly raise maxTags.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1503');
err.code;     // 'ZEN-1503'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1503'
```
