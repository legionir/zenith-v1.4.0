# ZEN-1402

> دامنه: **a11y** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1402

## علت

trap تودرتو با ترتیب پشتیبانی‌نشده.

_EN:_ Nested trap with unsupported order.

## نمونهٔ کد خطادار

```ts
import { createFocusTrap } from '@zenith/a11y';

// ❌ ناحیهٔ trap هیچ المان focusable ندارد
const trap = createFocusTrap(document.querySelector('#empty-panel'));
trap.activate();
```

## رفع

از پشتهٔ داخلی trap استفاده کنید؛ المان‌های trap را تودرتوی دستی نکنید.

_EN:_ Use the internal trap stack; do not nest traps manually.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1402');
err.code;     // 'ZEN-1402'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1402'
```
