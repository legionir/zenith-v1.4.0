# ZEN-2301

> دامنه: **runtime-core** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2301

## علت

onMount/onUnmount/onUpdate خارج از محدودهٔ directive/کامپوننت.

_EN:_ onMount/onUnmount/onUpdate outside directive/component scope.

## نمونهٔ کد خطادار

```ts
import { defineDirective } from '@zenith/runtime-core';

// ❌ bind باید Cleanup برگرداند
defineDirective({ name: 'probe', bind: () => {} });
```

## رفع

این قلاب‌ها فقط حین اجرای تابع directive یا setup کامپوننت مجازند.

_EN:_ These hooks are only allowed while running a directive function or component setup.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2301');
err.code;     // 'ZEN-2301'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2301'
```
