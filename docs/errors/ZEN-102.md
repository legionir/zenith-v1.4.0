# ZEN-102

> دسته: **Runtime** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-102

## علت

Invalid zen-for syntax.

ثابت کاتالوگ: `ErrorCode.RUNTIME_ZEN_FOR_INVALID_SYNTAX`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-102 گزارش/پرتاب می‌شود
const code = ErrorCode.RUNTIME_ZEN_FOR_INVALID_SYNTAX; // 'ZEN-102'
```

## رفع

خطای runtime/directive. ساختار DOM و نام دایرکتیو را بررسی کنید
(`zen-for` نیازمند `zen-key` و والد است؛ `zen-if` نیازمند والد). برای هر
دایرکتیو سفارشی، `defineDirective` را با `DirectiveMeta` ثبت کنید.
