# ZEN-2520

> دامنه: **tooling** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2520

## علت

پلاگین روی این bundler پشتیبانی نمی‌شود.

_EN:_ Plugin not supported on this bundler.

## نمونهٔ کد خطادار

```ts
import { compileTemplate } from '@zenith/compiler';

// ❌ خطای ابزار build (کامپایل/اسکن/emit) — جزئیات در details
compileTemplate('<div zen-if=""></div>');
```

## رفع

unplugin فقط rollup/vite/webpack/rspack را پشتیبانی می‌کند (SPEC §۴.۴).

_EN:_ unplugin supports only rollup/vite/webpack/rspack (SPEC §4.4).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2520');
err.code;     // 'ZEN-2520'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2520'
```
