# ZEN-9060

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9060

## علت

secret احتمالی در کد.

_EN:_ Potential secret in code.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

کلید/توکن را به env منتقل کنید (جایگزین Z600 قدیمی).

_EN:_ Move keys/tokens to env (replaces legacy Z600).

## نمونهٔ دسترسی به این کد
