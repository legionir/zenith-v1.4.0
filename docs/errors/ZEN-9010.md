# ZEN-9010

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9010

## علت

compileAndRender حذف‌شده (نام‌امن) استفاده شده است.

_EN:_ Removed compileAndRender is used (unsafe).

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

از zen-text یا zen-html با عبارت پیش‌کتبهٔ امن استفاده کنید (جایگزین Z100 قدیمی).

_EN:_ Use zen-text or zen-html with safe pre-compiled expressions (replaces legacy Z100).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9010');
err.code;     // 'ZEN-9010'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9010'
```
