# ZEN-1103

> دامنه: **storage** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1103

## علت

مهاجرت (migrate) نسخهٔ داده شکست خورد.

_EN:_ Data migration failed.

## نمونهٔ کد خطادار

```ts
import { createStorage } from '@zenith/storage';

// ❌ در حالت private مرورگر یا پر شدن سهمیه، ذخیره‌سازی محلی در دسترس نیست
const store = createStorage({ driver: 'local' });
store.set('profile', 'x'.repeat(6_000_000)); // → quota
```

## رفع

تابع migrate را بررسی کنید؛ دادهٔ کهنه حذف یا نسخه‌بندی مجدد شود.

_EN:_ Check the migrate function; old data may need pruning or re-versioning.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1103');
err.code;     // 'ZEN-1103'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1103'
```
