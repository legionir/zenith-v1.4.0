# ZEN-1002

> دامنه: **schema** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1002

## علت

کلید ناشناخته در گزینه‌ها.

_EN:_ Unknown key in options.

## نمونهٔ کد خطادار

```ts
import { s, validateOptions } from '@zenith/schema';

// ❌ مقدار ارسال‌شده با schema نمی‌خواند (یا کلید ناشناخته است)
validateOptions({ ttl: 'soon' }, s.object({ ttl: s.number() }));
```

## رفع

املای کلید را بررسی کنید؛ فهرست کلیدهای مجاز در details است.

_EN:_ Check the key spelling; allowed keys are listed in details.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1002');
err.code;     // 'ZEN-1002'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1002'
```
