# ZEN-1821

> دامنه: **adapters** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1821

## علت

مسیر در SSG رندر نشد.

_EN:_ Route failed to render during SSG.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

path در routes/paths پیکربندی وجود دارد و prerender سبز شد را بررسی کنید.

_EN:_ Verify the path exists in routes/paths and prerender passed.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1821');
err.code;     // 'ZEN-1821'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1821'
```
