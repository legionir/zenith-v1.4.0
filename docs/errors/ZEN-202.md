# ZEN-202

> دسته: **Resource** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-202

## علت

HTTP error while fetching the resource.

ثابت کاتالوگ: `ErrorCode.RESOURCE_HTTP_ERROR`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-202 گزارش/پرتاب می‌شود
const code = ErrorCode.RESOURCE_HTTP_ERROR; // 'ZEN-202'
```

## رفع

خطای Resource. در دسترس بودن endpoint، وضعیت HTTP و ترتیب
`fetch`/`dispose` را بررسی کنید؛ از `Resource.get()` پس از `dispose()` استفاده نکنید.
