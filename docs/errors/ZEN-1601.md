# ZEN-1601

> دامنه: **ui** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1601

## علت

المان trigger پیدا نشد.

_EN:_ Trigger element not found.

## نمونهٔ کد خطادار

```ts
import { createSelect } from '@zenith/ui';

createSelect({ options: [{ value: 'a' }], value: 'b' }); // ❌ value نامعتبر
```

## رفع

selector trigger را اصلاح یا وقت render بودن آن را بررسی کنید.

_EN:_ Fix the trigger selector or verify it is rendered.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1601');
err.code;     // 'ZEN-1601'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1601'
```
