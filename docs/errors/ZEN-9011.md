# ZEN-9011

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9011

## علت

استفاده از eval() یا new Function() در <script>.

_EN:_ Use of eval() or new Function() in <script>.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

الگوی eval برای امنیت (XSS) در Zenith ممنوع است (جایگزین Z101 قدیمی).

_EN:_ The eval pattern is forbidden in Zenith for security/XSS (replaces legacy Z101).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9011');
err.code;     // 'ZEN-9011'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9011'
```
