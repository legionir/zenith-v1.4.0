# ZEN-1001

> دامنه: **schema** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1001

## علت

گزینهٔ نامعتبر: نوع یا مقدار در مسیر مشخص‌شده انتظار schema را برآورده نمی‌کند.

_EN:_ Invalid option: type or value at the given path does not satisfy the schema.

## نمونهٔ کد خطادار

```ts
import { s, validateOptions } from '@zenith/schema';

// ❌ مقدار ارسال‌شده با schema نمی‌خواند (یا کلید ناشناخته است)
validateOptions({ ttl: 'soon' }, s.object({ ttl: s.number() }));
```

## رفع

مقدار را با نوع موردانتظار در schema تطبیق دهید؛ مسیر خطا در details آمده است.

_EN:_ Fix the value to the type expected by the schema; the error path is in details.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1001');
err.code;     // 'ZEN-1001'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1001'
```
