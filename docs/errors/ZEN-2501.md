# ZEN-2501

> دامنه: **tooling** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-2501

## علت

نام پروژه نامعتبر.

_EN:_ Invalid project name.

## نمونهٔ کد خطادار

```ts
import { compileTemplate } from '@zenith/compiler';

// ❌ خطای ابزار build (کامپایل/اسکن/emit) — جزئیات در details
```

## رفع

فقط [a-z0-9-_.]؛ بدون ..، مسیر مطلق یا جداکننده (create-zenith §۳.۹).

_EN:_ Only [a-z0-9-_.]; no "..", absolute path or separator (create-zenith §3.9).
