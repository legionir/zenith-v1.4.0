# ZEN-501

> دسته: **Compiler** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-501

## علت

Unknown directive at compile time.

ثابت کاتالوگ: `ErrorCode.COMPILE_UNKNOWN_DIRECTIVE`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-501 گزارش/پرتاب می‌شود
const code = ErrorCode.COMPILE_UNKNOWN_DIRECTIVE; // 'ZEN-501'
```

## رفع

خطای کامپایل. نام دایرکتیو را تصحیح کنید، importهای موردنیاز قالب را
به کامپایلر بدهید و خطای عبارت را پیش از build برطرف کنید.
