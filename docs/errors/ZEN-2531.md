# ZEN-2531

> دامنه: **tooling** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-2531

## علت

handler دوبار پاسخ داد (mock).

_EN:_ Handler responded twice (mock).

## نمونهٔ کد خطادار

```ts
import { compileTemplate } from '@zenith/compiler';

// ❌ خطای ابزار build (کامپایل/اسکن/emit) — جزئیات در details
compileTemplate('<div zen-if=""></div>');
```

## رفع

هر resolver فقط یک respond() صدا بزند (passthrough با respond ترکیب نشود).

_EN:_ Each resolver must call respond() only once (do not combine passthrough with respond).
