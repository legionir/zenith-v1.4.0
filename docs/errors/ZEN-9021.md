# ZEN-9021

> دامنه: **cli** • دسته: **Compiler** • لینک آنلاین: https://zenith.dev/errors/ZEN-9021

## علت

directive ناشناخته.

_EN:_ Unknown directive.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

املای zen-* را با فهرست directiveهای معتبر بسنجید (جایگزین Z201 قدیمی).

_EN:_ Check the zen-* spelling against the valid directive list (replaces legacy Z201).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9021');
err.code;     // 'ZEN-9021'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9021'
```
