# ZEN-1701

> دامنه: **realtime** • دسته: **Network** • لینک آنلاین: https://zenith.dev/errors/ZEN-1701

## علت

اتصال برقراری نشد.

_EN:_ Connection failed.

## نمونهٔ کد خطادار

```ts
import { createRealtime } from '@zenith/realtime';

// ❌ اتصال پیش از آماده بودن transport یا parser ناسازگار
const rt = createRealtime({ url: 'wss://example.test' });
rt.subscribe('room');
```

## رفع

URL/شبکه را بررسی کنید؛ backoff خودکار در حال تلاش مجدد است.

_EN:_ Check URL/network; automatic backoff is retrying.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1701');
err.code;     // 'ZEN-1701'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1701'
```
