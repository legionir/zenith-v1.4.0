# ZEN-304

> دسته: **SSR** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-304

## علت

Hydration mismatch between server and client markup.

ثابت کاتالوگ: `ErrorCode.SSR_HYDRATION_MISMATCH`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-304 گزارش/پرتاب می‌شود
const code = ErrorCode.SSR_HYDRATION_MISMATCH; // 'ZEN-304'
```

## رفع

خطای SSR/hydration. برای رندر سرور یک DOM سازگار (JSDOM/`@zenith/ssr`) بدهید
و مارک‌آپ سرور و کلاینت را یکسان نگه دارید تا hydration mismatch رخ ندهد.
