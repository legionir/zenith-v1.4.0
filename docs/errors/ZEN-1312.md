# ZEN-1312

> دامنه: **i18n** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1312

## علت

قالب ICU نامعتبر است.

_EN:_ Invalid ICU format.

## نمونهٔ کد خطادار

```ts
import { createI18n } from '@zenith/i18n';

// ❌ کلید یا locale در bundle ثبت نشده است
const i18n = createI18n({ locale: 'fa' });
i18n.t('missing.key.without.bundle');
```

## رفع

ساختار {plural, select, ...} را با مستندات i18n بسنجید.

_EN:_ Validate the {plural, select, ...} structure against the i18n docs.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1312');
err.code;     // 'ZEN-1312'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1312'
```
