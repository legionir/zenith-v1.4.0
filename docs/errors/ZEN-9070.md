# ZEN-9070

> دامنه: **cli** • دسته: **Network** • لینک آنلاین: https://zenith.dev/errors/ZEN-9070

## علت

fetch با scheme ناامن (http).

_EN:_ fetch with an insecure scheme (http).

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

https استفاده کنید یا الگوی URL را بازبینی کنید (جایگزین Z700 قدیمی).

_EN:_ Use https or review the URL pattern (replaces legacy Z700).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9070');
err.code;     // 'ZEN-9070'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9070'
```
