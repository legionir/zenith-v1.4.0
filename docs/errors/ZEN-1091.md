# ZEN-1091

> دامنه: **schema** • دسته: **Internal** • لینک آنلاین: https://zenith.dev/errors/ZEN-1091

## علت

sink لاگر خراب است (خطا هنگام نوشتن گزارش).

_EN:_ Logger sink is broken (error while writing a log record).

## نمونهٔ کد خطادار

```ts
import { s, validateOptions } from '@zenith/schema';

// ❌ مقدار ارسال‌شده با schema نمی‌خواند (یا کلید ناشناخته است)
validateOptions({ ttl: 'soon' }, s.object({ ttl: s.number() }));
```

## رفع

sink را جایگزین یا remove کنید؛ خطا فقط یک‌بار گزارش می‌شود و حلقهٔ لاگ نمی‌سازد.

_EN:_ Replace or remove the sink; the error is reported once and never loops.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1091');
err.code;     // 'ZEN-1091'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1091'
```
