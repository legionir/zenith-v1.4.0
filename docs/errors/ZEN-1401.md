# ZEN-1401

> دامنه: **a11y** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1401

## علت

المان focusable برای focus-trap پیدا نشد.

_EN:_ No focusable element found for focus-trap.

## نمونهٔ کد خطادار

```ts
import { createFocusTrap } from '@zenith/a11y';

const trap = createFocusTrap(document.createElement('div'));
trap.activate(); // ❌ هیچ المان focusable داخل container نیست
```

## رفع

حداقل یک عنصر focusable داخل container بگذارید یا trap را غیرفعال کنید.

_EN:_ Place at least one focusable element inside the container or disable the trap.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1401');
err.code;     // 'ZEN-1401'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1401'
```
