# ZEN-9030

> دامنه: **cli** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-9030

## علت

zen-for بدون zen-key.

_EN:_ zen-for without zen-key.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

zen-key یکتا برای هر آیتم اضافه کنید (DOM thrashing/state loss؛ جایگزین Z300 قدیمی).

_EN:_ Add a unique zen-key per item (DOM thrashing/state loss; replaces legacy Z300).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9030');
err.code;     // 'ZEN-9030'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9030'
```
