# ZEN-301

> دسته: **SSR** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-301

## علت

SSR requires a DOM implementation (JSDOM-compatible).

ثابت کاتالوگ: `ErrorCode.SSR_JSDOM_REQUIRED`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-301 گزارش/پرتاب می‌شود
const code = ErrorCode.SSR_JSDOM_REQUIRED; // 'ZEN-301'
```

## رفع

خطای SSR/hydration. برای رندر سرور یک DOM سازگار (JSDOM/`@zenith/ssr`) بدهید
و مارک‌آپ سرور و کلاینت را یکسان نگه دارید تا hydration mismatch رخ ندهد.
