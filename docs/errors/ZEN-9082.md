# ZEN-9082

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9082

## علت

link خارجی بدون rel=noopener.

_EN:_ External link without rel=noopener.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

rel="noopener noreferrer" به target=_blank اضافه کنید (جایگزین Z820 قدیمی).

_EN:_ Add rel="noopener noreferrer" to target=_blank (replaces legacy Z820).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9082');
err.code;     // 'ZEN-9082'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9082'
```
