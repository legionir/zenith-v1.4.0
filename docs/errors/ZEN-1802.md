# ZEN-1802

> دامنه: **adapters** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1802

## علت

template نامعتبر: نشانگر خروجی نیست.

_EN:_ Invalid template: no output marker.

## نمونهٔ کد خطادار

```ts
import { createNodeAdapter } from '@zenith/adapter-node';

// ❌ محیط اجرا handler موردانتظار adapter را ندارد
createNodeAdapter({ dir: './dist' })();
```

## رفع

<!--zen-outlet--> (یا کانفیگ marker) داخل template بگذارید.

_EN:_ Put <!--zen-outlet--> (or the configured marker) inside the template.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1802');
err.code;     // 'ZEN-1802'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1802'
```
