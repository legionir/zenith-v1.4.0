# ZEN-2001

> دامنه: **theme** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-2001

## علت

token تم نامعتبر.

_EN:_ Invalid theme token.

## نمونهٔ کد خطادار

```ts
import { createTheme } from '@zenith/theme';

// ❌ توکن رنگ ناشناخته در تم ارسال شده است
createTheme({ colors: { '--zen-brand': 'var(--missing)' } });
```

## رفع

نام token در تعریف theme وجود دارد و مقدار CSS-valid است.

_EN:_ Ensure the token exists in the theme definition and the value is CSS-valid.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2001');
err.code;     // 'ZEN-2001'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2001'
```
