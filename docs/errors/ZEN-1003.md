# ZEN-1003

> دامنه: **schema** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1003

## علت

JSON خراب در attribute.

_EN:_ Malformed JSON in attribute.

## نمونهٔ کد خطادار

```ts
<!-- ❌ JSON خراب در attribute (کاما/نقل‌قول نامعتبر) -->
<zen-crud zen-crud-options='{"url": "/api/items",}'>
```

## رفع

مقدار attribute باید JSON معتبر باشد (بدون کامای انتهایی و نقل‌قول تک).

_EN:_ The attribute value must be valid JSON (no trailing commas, no single quotes).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1003');
err.code;     // 'ZEN-1003'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1003'
```
