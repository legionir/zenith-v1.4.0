# ZEN-1101

> دامنه: **storage** • دسته: **Runtime** • لینک آنلاین: https://zenith.dev/errors/ZEN-1101

## علت

ذخیره‌گاه در دسترس نیست (مثلاً حالت private مرورگر).

_EN:_ Storage unavailable (e.g. browser private mode).

## نمونهٔ کد خطادار

```ts
import { createStorage } from '@zenith/storage';

// ❌ در حالت private مرورگر یا پر شدن سهمیه، ذخیره‌سازی محلی در دسترس نیست
const store = createStorage({ driver: 'local' });
store.set('profile', 'x'.repeat(6_000_000)); // → quota
```

## رفع

fallback به memory فعال شد؛ در صورت نیاز به persist از ذخیره‌گاه جایگزین استفاده کنید.

_EN:_ Fall back to the memory adapter or present a graceful notice to the user.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1101');
err.code;     // 'ZEN-1101'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1101'
```
