# ZEN-2103

> دامنه: **auth-oauth** • دسته: **Network** • لینک آنلاین: https://zenith.dev/errors/ZEN-2103

## علت

discovery شکست خورد.

_EN:_ Discovery failed.

## نمونهٔ کد خطادار

```ts
import { createOAuthClient } from '@zenith/auth-oauth';

// ❌ PKCE/redirect ناسازگار یا پاسخ token نامعتبر
createOAuthClient({ clientId: 'demo', redirectUri: '/callback' }).login();
```

## رفع

آدرس /.well-known/openid-configuration سرویس را بررسی کنید.

_EN:_ Check the /.well-known/openid-configuration address of the service.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-2103');
err.code;     // 'ZEN-2103'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-2103'
```
