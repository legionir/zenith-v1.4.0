# ZEN-303

> دسته: **SSR** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-303

## علت

AsyncLocalStorage unavailable for SSR isolation.

ثابت کاتالوگ: `ErrorCode.SSR_ASYNC_LOCAL_STORAGE_UNAVAILABLE`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-303 گزارش/پرتاب می‌شود
const code = ErrorCode.SSR_ASYNC_LOCAL_STORAGE_UNAVAILABLE; // 'ZEN-303'
```

## رفع

خطای SSR/hydration. برای رندر سرور یک DOM سازگار (JSDOM/`@zenith/ssr`) بدهید
و مارک‌آپ سرور و کلاینت را یکسان نگه دارید تا hydration mismatch رخ ندهد.
