# ZEN-302

> دسته: **SSR** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-302

## علت

Root element not found for SSR.

ثابت کاتالوگ: `ErrorCode.SSR_NO_ROOT_ELEMENT`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-302 گزارش/پرتاب می‌شود
const code = ErrorCode.SSR_NO_ROOT_ELEMENT; // 'ZEN-302'
```

## رفع

خطای SSR/hydration. برای رندر سرور یک DOM سازگار (JSDOM/`@zenith/ssr`) بدهید
و مارک‌آپ سرور و کلاینت را یکسان نگه دارید تا hydration mismatch رخ ندهد.
