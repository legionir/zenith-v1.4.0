# ZEN-404

> دسته: **Security** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-404

## علت

Insecure token storage detected.

ثابت کاتالوگ: `ErrorCode.SECURITY_INSECURE_TOKEN_STORAGE`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-404 گزارش/پرتاب می‌شود
const code = ErrorCode.SECURITY_INSECURE_TOKEN_STORAGE; // 'ZEN-404'
```

## رفع

خطای امنیتی. ورودی غیرقابل‌اعتماد را sanitize کنید (`@zenith/security`)،
نام ویژگی/شناسه‌های ممنوع را در عبارت‌ها به‌کار نبرید و از CSPRNG
(`secureId`) برای شناسه‌های امنیتی استفاده کنید.
