# ZEN-9050

> دامنه: **cli** • دسته: **Security** • لینک آنلاین: https://zenith.dev/errors/ZEN-9050

## علت

الگوی دایرکتوری‌تراورسال در مسیر.

_EN:_ Directory traversal pattern in path.

## نمونهٔ کد خطادار

```ts
# ❌ اجرای `zenith check` با قانون نقض‌شده (کدهای ZEN-90NN)
npx zenith check --strict   # rule violation
```

## رفع

مسیر را به ریشهٔ پروژه محدود کنید (جایگزین Z500 قدیمی).

_EN:_ Constrain paths to the project root (replaces legacy Z500).

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-9050');
err.code;     // 'ZEN-9050'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-9050'
```
