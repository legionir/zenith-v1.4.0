# ZEN-107

> دسته: **Runtime** • کد کلاسیک (سه‌رقمی؛ renumber نمی‌شود — DEC-020) • لینک آنلاین: https://zenith.dev/errors/ZEN-107

## علت

Component dispose failed.

ثابت کاتالوگ: `ErrorCode.RUNTIME_DISPOSE_FAILED`

## نمونهٔ کد خطادار

```ts
import { ErrorCode } from '@zenith/errors';

// هرجای کد که این شرط رخ دهد با کد ZEN-107 گزارش/پرتاب می‌شود
const code = ErrorCode.RUNTIME_DISPOSE_FAILED; // 'ZEN-107'
```

## رفع

خطای runtime/directive. ساختار DOM و نام دایرکتیو را بررسی کنید
(`zen-for` نیازمند `zen-key` و والد است؛ `zen-if` نیازمند والد). برای هر
دایرکتیو سفارشی، `defineDirective` را با `DirectiveMeta` ثبت کنید.
