# ZEN-1201

> دامنه: **cache** • دسته: **Validation** • لینک آنلاین: https://zenith.dev/errors/ZEN-1201

## علت

ttl نامعتبر است.

_EN:_ Invalid ttl.

## نمونهٔ کد خطادار

```ts
import { createCache } from '@zenith/cache';

// ❌ ttl باید عدد صحیح ≥ ۰ باشد
createCache({ ttl: -1 });
```

## رفع

ttl باید عدد صحیح ≥ ۰ (میلی‌ثانیه) باشد؛ ۰ یعنی بدون انقضا.

_EN:_ ttl must be an integer >= 0 (ms); 0 means no expiry.

## نمونهٔ دسترسی به این کد

```ts
import { createReservedError, errorDocsUrl } from '@zenith/errors';

const err = createReservedError('ZEN-1201');
err.code;     // 'ZEN-1201'
err.docsUrl;  // 'https://zenith.dev/errors/ZEN-1201'
```
